# BetterLocate

这是一个专门增强原版 /locate 的小模组，在/locate 的原有功能的基础上，增加了三个可选参数，同时还优化了搜索进度提示，以及更快的搜索算法。

## 原版 locate 算法说明

- 原版/locate structure <结构> 按放置网格计算。每种结构集都有一组参数，游戏用世界种子作为盐值做随机，算出哪些区块是潜在的结构起点。搜索时，从中心所在区块开始，逐圈向外扩展，每一圈只检查该圈上的候选区块，遇到第一个有效结构就返回，所以它给出的通常是“最近的一个”。默认搜索半径为1600格。

- 原版/locate biome <生物群系> 以玩家为中心，按水平 32 格、垂直 64 格的间隔设检查点，检查该处位置是否为目标生物群系，然后取最近的一个，默认最多搜索 6400 格。

- 原版/locate poi <兴趣点> 在 POI 索引里按 256 格范围内，查找距玩家最近的一个。

- 原版的locate指令只会给出坐标和距离。点击坐标会把 /tp 命令填入输入框。

## 本模组算法说明

- 生物群系取样本身是纯计算，因此可以按区块切片并行执行。

- 对结构的搜索分为两步，第一步通过后台线程并行算出可能生成结构的区块，第二步将候选区块逐个利用原版 findNearestMapStructure 做判定。

- 对兴趣点的搜索同原版 PoiManager 一致，模组只负责实现条件过滤、排序和统计。


## 本模组新增参数说明

下列参数均为可选，且顺序不限。

- radius <格>：允许的范围为1~100000，在指定半径内：若目标为生物群系，则统计所占区块数量，并给出最近一个区块的坐标；若目标为结构和兴趣点，则统计数量，并由近到远列出坐标与到访情况。若省略，则搜索范围为6400格，同原版一致。

- center <x y z>：指定搜索中心的坐标。若省略，则以玩家当前坐标为中心，同原版一致。

- chunks：visited / unvisited / any：指定区块被玩家到访过的情况，visited为只看玩家到访过的区块，unvisited为只看玩家从未到访过的区块，any为不。若省略，则默认any，同原版一致。

## 安全传送

本模组新增 `/safetp` 指令，用于在指定坐标附近寻找安全的传送高度，避免传送后卡入方块、从高处坠落、进入流体或细雪等危险位置。

```
/safetp [目标选择器] [x y z] [top/bottom] [next] [normal/force] [radius]
```

- 目标选择器可省略，默认为执行者自己；坐标可省略，默认为目标实体当前坐标。

- 坐标使用原版坐标写法，支持绝对坐标和相对坐标，例如 `~ ~ ~`；使用 Tab 可以一次补全当前坐标。

- `top` 从建筑上限向下寻找，`bottom` 从最低建筑高度向上寻找。省略时沿用该实体上一次的方向，没有记录时默认为 `top`。

- `next` 从上一次找到的位置继续寻找下一个位置。使用 `top` 时继续向下，使用 `bottom` 时继续向上。

- `normal` 只传送到安全位置；`force` 在找不到安全位置时允许传送到满足基本站立条件的强制位置。

- `radius` 是 X/Z 平面的搜索半径，默认为 3。搜索会从中心列开始，按逐渐扩大的方形外圈检查各列。

例如：

```
# 在目标坐标附近寻找安全位置
/safetp 114 64 514 top normal 3

# 使用当前位置的 X/Y/Z，并从上往下寻找
/safetp ~ ~ ~ top normal 3

# 继续向下寻找下一个位置
/safetp next
```

## 使用示例

下列示例的功能与原版一致。

```
# 最近的平原村庄
/locate structure minecraft:village_plains

# 上述指令等价于如下指令
/locate structure minecraft:village_plains radius 1600 center ~ ~ ~ chunks any

# 最近的沙漠
/locate biome minecraft:desert

# 上述指令等价于如下指令
/locate structure minecraft:village_plains center ~ ~ ~ radius 6400 chunks any

# 最近的盔甲匠工作站点
/locate poi minecraft:armorer

# 上述指令等价于如下指令
/locate structure minecraft:village_plains chunks any center ~ ~ ~ radius 256

```
下列示例的功能使用到本模组新增参数。

```
# 半径 3000 格内所有平原村庄
/locate structure minecraft:village_plains radius 3000

# 统计半径2000格范围里有多少平原区块
/locate biome minecraft:plains radius 2000

# 统计半径3000格内已去过的区块有多少沙漠
/locate biome minecraft:desert radius 3000 chunks visited

# 搜索从未到访过的区块里的村庄
/locate structure minecraft:village_plains radius 1500 chunks unvisited

# 以 (0,64,0) 为中心，搜索半径 300 格内、已到访的区块里的盔甲匠
/locate poi minecraft:armorer center 0 64 0 radius 300 chunks visited

```

一种示例输出如下。

```

  #2  (256, ~, -2560)  距离 2573.9 格  【未到访】  [安全传送]
```

## 对玩家到访区块统计的说明

- 对玩家到访区块的统计，通过读存档 region 文件的 4KB 头表完成。玩家未到访的区块在存档中缺少对应记录，据此可判断某个区块的到访状态。

- 生物群系和兴趣点都是只读的，搜索这两项，不会向地图中写入区块存储，因而不会影响玩家到访情况。

- 对于结构的搜索，其判定候选区块时会加载/生成区块，因此被判定过的候选区块将不再是【未到访】状态，这是原版实现locate指令的固有代价，与本模组的判定无关。

- 具体而言，本模组在识别到搜索结构、且 chunks 参数非 any 后，会创建一个“到访索引”，先读入存档头表，然后逐个筛选区块：先检查放置规则，再检查群系/地形（在这一步才会生成区块），筛选完毕后，再根据“到访索引”所示到访状态输出结果，因索引先于区块生成，所以本次搜索所得结构的到访状态为【未到访】；这些在搜索过程中生成的区块被服务端卸载时，会被自动写入存档，下次搜索到这些区块，其到访状态则为【已到访】。

- 玩家以任何方式搜索任何结构，即使未指定 chunks 参数，只要候选区块进入了群系/地形检查这一步，那么在搜索结束后，相应区块内结构的到访状态也为变为【已到访】，并且这个区块内的其他结构（即使并非上次搜索的目标）被搜索时，其到访状态也为【已到访】。
